`qt-6.12.0-NOTICES.txt` collects license, copyright, attribution and REUSE files
from the official PySide/Shiboken, qtbase, qtsvg and qtimageformats 6.12.0 source
archives. It also contains upstream notices for optional components and examples
that DodgeSatelite does not ship. The unmodified source archives and verified hashes
are supplied as `Qt-6.12.0-corresponding-sources.zip` in the GitHub Release.
