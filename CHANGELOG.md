# Changelog

## 0.2.0 — 2026-10-14

Use dodge satelite consistently for the desktop application, Python package,
CLI, NINA assemblies, repository links, screenshots and release packages. The
new repository starts with a fresh source history. A copy-only saved-sequence
migration command updates NINA instruction type references without executing
JSON content or overwriting the original file. Prediction geometry is unchanged.

## 0.1.0 — 2026-10-14

Initial experimental release: CelesTrak CSV/cache, input profiles,
satellite/illumination geometry, constrained fixed-exposure scheduling,
CSV/JSON/SVG export, bilingual desktop GUI, CLI, synthetic demo, automated tests,
Windows packaging and CI configuration.

This version has not been validated against measured satellite trails. Full
catalog coverage, calibrated error bounds, camera integration and moving targets
are outside its scope. Published on GitHub with the project owner's approval.
